KUNSKAPSTRÄDET / THE LEARNING TREE

Windows 10/11, 64-bit

SVENSKA
Dubbelklicka på NumberCatch.exe. Ingen installation behövs.
Välj räknebilden (1) eller boken (2) i startmenyn.
I Inställningar kan du byta språk till English.

Flytta korgen: piltangenterna, A/D eller musen.
F11: helskärm. Mellanslag: pausa. R: börja om.
Esc: lämna helskärm eller gå tillbaka till menyn.
Ett helt krympt träd avslutar spelet. Tryck R eller Enter för att börja om.
Muspekaren döljs när du spelar och visas igen vid paus och spelets slut.

ENGLISH
Double-click NumberCatch.exe. No installation is needed.
Choose the equation (1) or the book (2) from the start menu.
Choose Inställningar > English to switch languages.

Move: arrow keys, A/D, or mouse.
F11: full screen. Space: pause. R: restart.
Esc: leave full screen or return to the menu.
An empty tree ends the game. Press R or Enter to play again.
The pointer hides during play and returns on pause or game over.

SHARING
Zip this entire folder and send it to another Windows 10/11 x64 computer.
Extract the ZIP before starting NumberCatch.exe.
All 220 pictures are embedded in the executable. Python, Rust, and separate
assets are not needed. The game works offline.

Language preferences are saved locally as NumberCatch.settings next to the
executable. This optional file is not required to play.
