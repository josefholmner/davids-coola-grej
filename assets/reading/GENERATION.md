# Reading illustrations

220 individual cartoon vocabulary pictures generated with the built-in image_gen tool, one generation per picture. Original outputs are preserved as PNG files. The full prompt set is saved in prompts.json, and the intended Swedish/English subjects are in vocabulary.json.

All pictures are embedded into the Windows executable at build time. They are decoded at their original resolution and scaled with high-quality interpolation. No external network service is used when playing.

The expanded collection preserves the original 120 objects and adds 100 new bilingual entries. Each Swedish and English label is 3–7 letters long.
